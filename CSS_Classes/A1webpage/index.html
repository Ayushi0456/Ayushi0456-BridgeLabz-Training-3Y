Examples of hover, focus, active and nth-child()

:hover

Hover Over Me

The :hover pseudo-class changes the appearance when the mouse is placed over an element.

:focus

The :focus pseudo-class applies a style when an element receives keyboard or mouse focus.

:active

The :active pseudo-class applies a style while an element is being clicked or pressed.

:nth-child()

  • First Item
  • Second Item

The :nth-child() pseudo-class selects an element based on its position among its siblings.
